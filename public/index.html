나라장터 입찰공고 AI 비서

Claude·ChatGPT·Cursor에서 나라장터 입찰공고를 검색하고, 조건에 맞는 신규 공고를 매일 아침 이메일로 받는 MCP 서버입니다.

연결 방법

MCP 엔드포인트: https://kr-public-mcp.<your-subdomain>.workers.dev/mcp

Claude (claude.ai / Claude Code)

claude mcp add --transport http narajangteo https://kr-public-mcp.<your-subdomain>.workers.dev/mcp

ChatGPT / Cursor

MCP 설정에 위 URL을 Streamable HTTP 서버로 추가하세요.

Pro 이용권

무료 도구(공고 검색·상세 조회)는 키 없이 일 30회까지 쓸 수 있습니다. 사전규격 조회·낙찰 분석·이메일 알림은 Pro 이용권(크몽 판매)이 필요합니다. 구매 후 발급받은 키를 Authorization: Bearer <키> 헤더로 전달하세요.
